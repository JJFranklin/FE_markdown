## Project Setup

vue3 + typeScript + pinia + vue-router + element-plus

```sh
pnpm install
```

```sh
pnpm dev
```

```sh
pnpm build
```

### Lint with [ESLint](https://eslint.org/)

```sh
pnpm lint
```
