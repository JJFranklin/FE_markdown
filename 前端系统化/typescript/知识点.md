重点类型处理

TypeScript 有两个“顶层类型”（any和unknown），但是“底层类型”只有never唯一一个

1、any 类型: 表示任何类型，同时可以赋值给其他任何类型，其他类型也可以赋值给 any 类型
2、unknown 类型，表示 ts 推断出的其他类型，只能赋值给 any 和 unknown 类型的值，但是不能赋值给除了（unknown、any）的其他类型
其他任何类型的值都能赋值给 unknown 类型。
3、可以通过类型缩小 typeOf 来进一步确认数据的类型，在进行赋值
4、never 类型：空类型，不包含任何值
不能给此类型的值赋值，但是可以赋值给任何其他类型
5、undefined 和 null 既是值又是类型，任何类型的值都可以赋值为 undefined 和 null，和javascript一致；

```ts
let s:unknown = 'hello';
if (typeof s === 'string') {
  s.length; // 正确
}
```

6、number [] 是readonly:number[] 的子类型
readonly:number[] 需要注意的点
1、不能作为数组传值
```typescript
let a:readonly number[] = [1,2,3];
function sum(arr:number[]){
}
sum(a) // 会报错
```
2、readonly关键字不能与数组的泛型写法一起使用

```typescript
// 报错
const arr:readonly Array<number> = [0, 1];
```
