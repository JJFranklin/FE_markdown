commonJS

require('./模块id');

1、node 环境支持
2、动态依赖，只有代码运行才能知道引用的是哪个模块
3、动态依赖是同步的，只有reqire 完成，才能执行下面的步骤
4、运行之后 会将引用的模块加入到缓存中，下次使用的时候，会直接从缓存中获取
5、导入的是模块的引用，引入模块后，修改模块中的值，会影响原本的模块的值，进而影响此模块在其他模块中的使用

Es Module

1、同时支持静态依赖和动态依赖
静态依赖在运行前就要确定依赖关系
2、动态依赖是异步的
3、符号绑定，导入模块后，修改原本模块中的值，会影响到使用此模块的其他地方，会同步进行改变，
3.1、优化方式：可以将引入的模块，重新赋值给另一个变量，其他模块修改的时候，就不会影响了


```js
// 静态依赖，必须在最顶层，先申明，再使用
import a from './a';

// 动态依赖，通常是用在异步路由
// 返回一个promise对象，所以后面可以链式调用 then 
// 运行的时候才能确定依赖关系
import('./a').then();

// 3、避免方式
import {count} from './a'
// 此时在 a.js 中修改count的值，不会影响到newCount的值
let newCount = count;
```
